让真实的 AI API Key
永远不必交给员工

KeyKeep（钥守）是私有化部署的企业 AI API 统一管理与分发软件。公司统一保管真实上游凭据，员工只拿到可撤销、可限额、可审计的虚拟 Key —— 员工用现有 AI 工具照常工作，真实凭据、预算和审计始终握在公司手里。

内置便携数据库、运行时与演示上游，双击安装即可在单机跑通完整流程，无需准备真实凭据。

三件事，握在自己手里

把「发 Key」变成一件可控、可查、可收回的事，而不是一次性交出去的信任。

01

真实凭据不出管理面

上游 API Key 加密保存在管理端，只由网关读取。员工与员工侧工具从头到尾接触不到明文。

02

撤销即时生效

虚拟 Key 随手可撤，撤销后立即拒绝后续调用。疑似泄漏时不必全网更换真实凭据。

03

用量与审计可核

每次调用按模型计价入账，精确到员工与 Key；登录、签发、撤销、失败全程留痕。

核心功能

从签出一枚虚拟 Key，到看懂这个月花在哪里，是一条完整闭环。

虚拟 Key 签发与撤销

批量签发，明文仅显示一次；撤销即时生效，之后只展示密钥指纹。

凭据加密集中托管

真实上游凭据 AES-256-GCM 加密存储，仅管理面可写入。

多供应商与模型映射

逻辑别名映射到上游模型，可多条映射分流；支持 OpenAI / Anthropic 协议、SSE 流式与工具调用。

两级限流与两级预算

Key 级 / 全局级限流，员工级 / 全局级预算，超限自动拒绝，不再事后才发现失控。

计量账本与价格版本

按模型目录计价，价格支持版本管理，用量明细可筛选、可查、可核。

规则式脱敏

按策略替换敏感内容后再转发，减少提示词把敏感信息带往上游的风险。

审计日志与员工自助

管理操作与调用失败全程留痕；员工自行查看接入方式、自己的 Key 与用量。

签名升级与一键回滚

版本目录 + 指针切换，升级包带 Ed25519 签名清单与 SHA-256 校验，失败自动保留旧版。

安全与私有化

设计上把「数据留在自己这里」当作默认，而不是一个需要额外配置的选项。

数据留在本机 / 内网

凭据、账本与审计数据全部保存在部署侧，不回传软件方。

凭据加密、不明文落日志

真实上游凭据 AES-256-GCM 加密存储，不以明文出现在日志与诊断信息中。

升级包先验签再安装

Ed25519 签名清单 + SHA-256 校验，任一环节不通过都不会安装，失败自动保留旧版。

控制台默认只听本机

默认仅监听 127.0.0.1，不对外暴露管理入口。
